    Data confidence. Every figure and flag on this report is Authoritative (a confirmed mapping), Inferred (a heuristic fallback — see "Superstars-Wallet Inferred Categories" below), or Unknown (an unmapped type code — see "Unclassified Type Codes" below). Inferred and Unknown values must not be used, on their own, as grounds for an account suspension, fraud determination, compliance conclusion, financial reconciliation, or any automated support action. This tool is read-only and does not take any such action itself — treat lower-confidence figures as a lead to corroborate against authoritative source data, not a finding.
